## W 魔改版（0.2.10-w.1）改动清单

### 1. 更新 DeepSeek 定价表（2026-09-10 调价）

原版内置的是 2026-08-17 生效的价格。DeepSeek 于 2026-09-10 下调了 Flash 系列非高峰时段价格，本版已同步：

| deepseek-flash（V4.1-Flash） | 空闲时段 | 高峰时段 |
|---|---|---|
| 输入（缓存命中） | 0.05 → **0.02** 元/百万 tokens | 0.10 → **0.04** 元/百万 tokens |
| 输入（缓存未命中） | 1.5 → **1.0** 元/百万 tokens | 3.0 → **2.0** 元/百万 tokens |
| 输出 | 4.5 → **4.0** 元/百万 tokens | 9.0 → **8.0** 元/百万 tokens |

- `deepseek-v4-pro` 价格未变（0.15/0.3、4.5/9.0、13.5/27.0），保持原版
- `PRICING` 新增 `deepseek-flash` 模型 key（原版靠默认档兜底，新模型名下同样按正确价计）
- 价格表位置：`lib/index.js` 顶部 `BASE_PRICE` / `PRO_PRICE` / `PRICING` 常量，后续 DeepSeek 再调价可自行修改

### 2. 常驻显示（下拉框，单选）

菜单「常驻显示」下拉框，四选一：

| 选项 | 效果 |
|---|---|
| **无**（默认） | 普通模式：气泡 5 秒自动收起；点击气泡出随机台词，再点关闭 |
| **峰谷时段** | 常驻显示「当前时间段为：高峰(红)/空闲(绿) + 今日已用」，随余额刷新自动更新 |
| **余额** | 常驻显示「余额 + 今日已用」，不自动收起；点击气泡出随机台词，看完自动回余额视图 |
| **对话气泡** | 随机台词自动轮播（每 5 秒换一组，气泡常驻） |

- 消耗金额泡泡弹出期间常驻视图暂停，泡泡关闭后自动回到常驻视图
- 配置持久化（`persistMode` 字段），重启后保持

### 3. 梁文峰时段锁定（勾选框）+ 锁定气泡轮播

菜单「峰谷」行新增 **高峰锁定** 勾选框。勾选后，处于**高峰时段**（工作日北京时间 9:00–12:00、14:00–18:00；周末全天谷价不算）且当前会话模型为 **DeepSeek** 时：

- 聊天输入框右侧的**发送按钮隐藏**（「停止生成」按钮保留，可正常中断生成）
- **键盘 Enter 发送被拦截**（仅聊天输入框内，不影响页面其他区域）
- 气泡弹出锁定提示

**锁定气泡在两个视图间轮播**（间隔 = 菜单「轮播」秒数，默认 5 秒，填 0 不轮播）：

- 视图一：`梁文峰时段` / **锁定中**（红） / `DeepSleep...`
- 视图二：`距离梁文谷还有：` / **HH:MM:SS**（红字倒计时，逐秒跳动，到 12:00 / 18:00 归零） / `亿万鲸子仍需忍耐`

峰时结束自动解锁（按钮恢复、气泡收起或回常驻视图）；切到非 DeepSeek 模型立即解锁，切回再锁。

### 4. 菜单重排 + 全项悬停说明

- 菜单收窄成竖版紧凑布局（4 行设置 + 2 行开关）：
  - `大小 [滑条][数值] 气泡开关 ☑`
  - `音效 [下拉] 音量 [滑条] 90%`
  - `用量 [下拉] 常驻显示 [下拉]`
  - `峰谷 [下拉] 高峰锁定 ☑ 轮播 [秒数] 秒`
  - `每轮消耗提示 ☑ 自动关闭 [秒数] 秒`
  - `避让滚动条 ☐ 宽度 [px] px`
- **所有菜单项（标签与控件）都有悬停说明**：鼠标放上去弹出功能解释（如常驻显示的四种模式、高峰锁定的生效条件、轮播间隔含义等），说明文案集中在 `lib/index.js` 的 `MENU_TIPS` 表，可自行修改

### 5. 插件标识（避免与原版混淆）

- 插件名：`dsh-whale-widget` → `dsh-whale-widget-w`
- 版本号：`0.2.10` → `0.2.10-w.1`
- `package.json` 新增 `original` 字段声明原作来源；`cordis.patch.yml` 挂载 id/name 同步改为 `dsh-whale-widget-w`，可与原版共存不冲突

## 安装（W 魔改版）

与原版方式一致，把来源换成 W 版仓库即可（本地安装）：

```powershell
dsh plugin --profile web add link:<本目录绝对路径>
```

或从 GitHub 安装（上传后）：

```powershell
dsh plugin --profile web add github:<你的用户名>/dsh-whale-widget-w
```

> ⚠️ 注意：本版与原版 `dsh-whale-widget` 可以共存，但气泡是同一个路由位（右下角），**建议二选一启用**，卸载另一个用 `dsh plugin --profile web remove dsh-whale-widget`。
